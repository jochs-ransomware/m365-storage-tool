One-time Azure App Registration

This tool signs in as a Global Admin using Microsoft's standard OAuth flow — no passwords are ever entered here, and no client secret is needed. You just need to register the app once in Azure AD.

Create an App Registration

Go to portal.azure.com → Azure Active Directory → App registrations → New registration. Name it anything (e.g. "M365 Storage Tool").

For Redirect URI: choose Single-page application (SPA) and enter the exact URL where this file is hosted — including http://localhost if testing locally. This must match exactly.

Add API permissions

Go to API permissions → Add a permission → Microsoft Graph → Delegated permissions. Add these:

Reports.Read.All User.Read

Then click Grant admin consent. The status dots should turn green.

Copy your Application (Client) ID

On the App Registration Overview page, copy the Application (Client) ID. That's the only value you need below — no secrets.

Connect your tenant

From the App Registration Overview page in Azure AD
Must exactly match the redirect URI you entered in Azure AD
Clicking "Sign in" opens Microsoft's login page. After you authenticate, you'll be redirected back here and the data will load automatically. Only read-only report permissions are requested.
